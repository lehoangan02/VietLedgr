## Core Principles

- **Data integrity first:** Enforce constraints in both SQL and SQLAlchemy to keep inventory, ledger, and auth data consistent.
- **Secure by default:** Apply RBAC, token expiry, and store-level access guards across the stack.
- **Test what matters:** Aim for high coverage on CRUD, inventory, and accounting flows; automate regression checks where possible.
- **Document continuously:** Update these pages alongside code changes so new collaborators can onboard quickly.

## Contributing

1. Branch from `main` or the relevant feature branch.
2. Update docs in the same PR as your code changes when behavior shifts.
3. Run `pnpm build` in `docs/docs-app` to ensure MDX and search indexes compile before opening a review.

Found a gap or outdated section? Open an issue or drop a note in the team channel so we can keep this source of truth fresh.
